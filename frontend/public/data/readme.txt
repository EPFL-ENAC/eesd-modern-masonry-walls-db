Database of 198 shear and compression tests on modern masonry walls reported in the literature.
Last update: 24/09/2026

The information contained in this database is primarily taken from:
Morandi et al., 2018:  P. Morandi, L. Albanesi, F. Graziotti, T. Li Piani, A. Penna, G. Magenes, Development of a dataset on the in-plane experimental response of URM piers with bricks and blocks, Construction and Building Materials 190 (2018) 593–611. doi:10.1016/j.conbuildmat.2018.09.070
Morandi& Albanesi, 2026: P. Morandi, L. Albanesi, Experiment-based definition of limit states and derivation of in-plane drift capacity of brick and block urm walls for seismic design and assessment, Bulletin of Earthquake Engineering 24 (3) (2026) 1635–1683. doi:10.1007/s10518-025-02313-8
and further complemented.

The database is contained in 'ModernMasonryDatabase_EIA.xlsx'.
The folder '01_references' contains the details of the references where the data of each test specimen is contained. The information is stored in the csv file "ModernMasonryDatabase_EIA_References.csv", indicating the ID name that is referred in the "Reference" column of ModernMasonryDatabase_EIA_Database.csv
The folder '02_fd_curve' contains the force-displacement curves in terms of drift [%] and force [kN] stored in csv files, identified according to the N column in ModernMasonryDatabase_EIA_Database.csv that specifies the specimen number and following the format "fd_curve_N"
The folder '03_envelope' contains the backbone envelopes in the positive and negative direction in terms of drift [%] and force [kN] stored in csv files, identified according to the N column in ModernMasonryDatabase_EIA_Database.csv that specifies the specimen number and following the format "envelope_N_pos" or "envelope_N_neg"
The folder '04_bilinear_curve' contains the bilinear idealisations in the positive and negative direction in terms of drift [%] and force [kN] stored in csv files, identified according to the N column in ModernMasonryDatabase_EIA_Database.csv that specifies the specimen number and following the format "bilinear_N_pos" or "bilinear_N_neg"
The folder '05_fig_setup' contains the figures showing the test setup, identified according to the N column in ModernMasonryDatabase_EIA_Database.csv that specifies the specimen number and following the format "fig_setup_N"
The folder '06_fig_failmode' contains the figures showing the failure mode of the specimen tested, identified according to the N column in ModernMasonryDatabase_EIA_Database.csv that specifies the specimen number and following the format "fig_failmode_N"
The folder '07_fig_materials' contains the figures showing the material (units, mortar or assembly) of the test specimen, identified according to the N column in ModernMasonryDatabase_EIA_Database.csv that specifies the specimen number and following the format "fig_mat_N"
The folder '08_fig_cracks' contains the figures showing the results of crack measurements performed on test specimens, identified according to the N column in ModernMasonryDatabase_EIA_Database.csv that specifies the specimen number and following the format "fig_cracks_N"
